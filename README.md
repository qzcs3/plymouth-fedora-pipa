# plymouth-fedora-pipa
script to install plymouth on fedora pipa


# Installition

install the script
```
curl -L -o pipaPlymouth.sh https://raw.githubusercontent.com/qzcs3/plymouth-fedora-pipa/refs/heads/main/setupPlymouth.sh
```

chmod the script
```
chmod +x pipaPlymouth.sh
```

run the script
```
./pipaPlymouth.sh
```
congrats
